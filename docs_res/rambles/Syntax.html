hbDoc Syntax

Document declarations with an hbDoc comment block immediately before them. The tag names the kind of entry; brief and details describe it.

--[[/hbdoc
\class Example
\brief A documented Lua table.
\details Longer notes can go here.
]]
local Example = {}

--[[/hbdoc
\function Example.run
\brief Runs the example.
]]
function Example.run(input)
    return input
end

Use \class, \function, or \macro to document an entry. Qualified Lua functions such as Example.run appear as members of their documented class or table. For C and C++, put /// \brief and optional /// \details comments directly above the declaration.

For custom HTML in a C/C++ documentation comment, put markup between /// \HTMLstart and /// \HTMLend. Rambles like this file are separate HTML fragments named after their page; they are shown beside the formal documentation and should not include <html>, <head>, or <body> tags.
